# The Missing Folio | Client playtest

A portrait-first browser mystery with a camera-scanned test seal.

## Publish on GitHub Pages

1. Extract this ZIP and add its contents directly to the root of the GitHub repository. Keep the hidden `.nojekyll` file and the `assets` and `vendor` directories.
2. Push the files to `main`.
3. In the repository, open **Settings → Pages**. Set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. Open the HTTPS address shown in Settings → Pages. Use that address for the playtest so the phone browser can request camera access.

[GitHub Pages setup](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Share the demo

- Open the site in portrait mode and enter playtest code **12345**.
- For the AR demo, download the test seal from the in-game **Journal**, then print it or display it on a second screen. Use the game’s Scan button and grant camera access when prompted.
- The code is a demo gate. Visitors who can access the page can inspect it and download the files. Progress is saved in the player’s browser on that site.
